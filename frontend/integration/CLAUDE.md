# Integration — pointer

Substantive docs for this domain live at `backend/integration/CLAUDE.md`. `sap-interface-ui.mts` (Admin > Interface) also renders the SAP staging console: a Staging tab per staging object (plant combobox, batch list with status pills and counts, held reason with the list of orders an apply would delete, Validate / Apply / Confirm & Apply / Discard, rejected-rows drawer with CSV, Excel/CSV test upload, manual/auto apply switch, Refresh = on-demand poll), plus an **Outbound** panel (Send to SAP, ready/sent/error tiles, error-rows CSV) and an **Archive** panel (orders deleted by a snapshot in the last 30 days, Restore) on the planned-orders object. A validated batch that will delete rows opens the same confirm modal as a held one (running orders are marked and the text says they are deleted too, recoverable from the Archive for 30 days); raw reject/warning/409 codes are mapped to `ui.sap_stage_reject_*` / `ui.sap_stage_warn_*` text. Wire shapes mirror `/sap/staging/*`; all text goes through the `ui.sap_stage_*` / `ui.sap_send_*` / `ui.sap_archive*` i18n keys in the five locales; tests in `tests/modules/integration/sap-interface-ui.test.mjs`.

`Interface.showTab(tab, objectKey = 'stage_planned_orders')` (`sap-interface-ui.mts`) selects an Admin > Interface tab and staging object programmatically; the Admin deep link `sap:<tab>` (Overview SAP signal -> Staging) calls it.
