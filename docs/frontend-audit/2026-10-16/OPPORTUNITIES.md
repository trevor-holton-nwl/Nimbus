# Planner opportunities and follow-up decisions

This register complements the implemented defects and productivity improvements in the four domain reports. It distinguishes useful follow-up work from features already present. None of the deferred entries is represented as delivered. Priority is relative to this audit, not a product roadmap commitment.

| Planner task | Delivered design / acceptance boundary | Evidence owner |
